# Wish Jar

A Thanksgiving website: visitors type a wish, it falls through the dark into a glass jar,
and every wish rests there on a paper slip in fall colours.

Vanilla HTML/CSS/JS with no build step, Vercel functions in `/api`, Upstash Redis for storage.

```sh
npm install               # Playwright, for screenshots only
npm run dev               # http://localhost:5173 with an empty in-memory jar
npm run dev -- --seed     # ...with 60 sample wishes
npm test                  # node --test: jar layout, validation, Redis client, API
npm run screenshots       # 1440x900 and 390x844 into screenshots/, with in-browser checks
node scripts/journey-shots.js   # a wish falling into the jar, frame by frame
node scripts/live-shots.js      # empty jar, arrivals, rate limit, API down
```

- `js/layoutJar.js` decides where every slip rests. It is pure and deterministic: the same
  wishes give the same jar on every device. Randomness is seeded from wish ids, and text
  widths come from a fixed DM Serif Display table (`js/fontMetrics.js`, regenerated by
  `npm run measure-font`).
- `js/scene.js` draws the room and the glass, `js/jarView.js` the slips, and `js/drop.js`
  animates a wish falling in.
- `lib/` holds the API: validation, profanity filter, rate limiting and the Upstash REST
  client. `api/` holds the thin Vercel functions around it.
