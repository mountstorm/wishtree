# Wish Tree

A Thanksgiving website where visitors type a wish, it falls onto a small Earth, and all the
wishes together grow into one tree made of the wish text itself.

Vanilla HTML/CSS/JS, no build step.

```sh
npm install          # Playwright, for screenshots only
npm run dev          # http://localhost:5173
npm test             # layout tests (node --test)
npm run screenshots  # 1440x900 and 390x844 into screenshots/, plus a real-browser overlap check
```

- `js/layoutTree.js` grows the tree. It is pure and deterministic: the same wishes give the
  same tree on every device, with randomness seeded from wish ids and text widths taken
  from a fixed DM Serif Display table (`js/fontMetrics.js`, regenerated by `npm run measure-font`).
- `js/scene.js` draws the sky and Earth, and `js/treeView.js` draws a layout as SVG
  `<textPath>` branches.
